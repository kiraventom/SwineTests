# SwineTests

Симулятор [SwineBot](../SwineBot): гоняет бота по виртуальному времени, подсовывает
апдейты от шести тестовых пользователей с разными стратегиями кормления и проверяет,
что бот отвечает без ошибок. Telegram не трогается — все отправители замоканы.

## Запуск

Репозитории должны лежать рядом: `../SwineBot` — сам бот.

```bash
dotnet run -c Debug -- --days 200
```

| аргумент | по умолчанию | зачем |
|---|---|---|
| `--days <N>` | обязательный | сколько виртуальных дней прогнать (24 тика в день) |
| `--db <path>` | `~/.local/share/SwineTests/users.db` | своя база; файл пересоздаётся на каждом прогоне |
| `--achiev <path>` | `../SwineBot/Achievements/achiev_data.json` | данные ачивок |
| `--verbose` | выкл. | печатать текст каждого сообщения бота |
| `--no-slaughter` | выкл. | не забивать свиней каждые 60 дней |

Код возврата: 0 — все апдейты обработаны и все инварианты сошлись, 1 — есть провалы,
2 — неверные аргументы.

## Что делает прогон

- Шесть пользователей в одной группе (`Chat.Id = -1337`), у каждого свой свин.
  TelegramId детерминированный: `1000 + (int)strategy`, чтобы прогоны были сравнимы.
- Каждый тик (час) пользователь решает, кормить ли свина по своей стратегии:
  `RegularNoOverfeed` (раз в ~25 ч), `Overfeed12/8/6/4` (перекорм соответственно),
  `Overfeed12Then6` (12 ч, а после ачивки Overfeed 31 — 6 ч).
- Каждые 60 дней (кроме `RegularNoOverfeed`) — `/slaughter yes`.
- В конце: сводка по свинам, ачивки по типам, `/top`, картинка `/history` и инварианты.

## Инварианты

Проверяются в конце прогона, числа случайны, поэтому проверки качественные:

- вес свина не уходит ниже 1 кг;
- стратегия без перекорма не получает ачивку Overfeed;
- `Overfeed4` блюёт чаще, чем `RegularNoOverfeed`;
- спокойное кормление набирает вес лучше жадного (осмысленно с `--no-slaughter`);
- забои идут ровно раз в 60 дней (или их нет с `--no-slaughter`);
- `/history` отдаёт непустой PNG.

## Моки

| мок | что подменяет |
|---|---|
| `MockBotMessageSender` | отправку сообщений; копит тексты и отдаёт фейковые `Message.Id` — на них опирается `/duel`, запоминая id сообщения с кнопками |
| `MockCallbackQueryAnswerer` | тосты на нажатия инлайн-кнопок |
| `MockMessageEditor` | правку сообщений (вызов дуэли переписывается итогом) |
| `MockDateTimeNowProvider` | часы бота |
| `MockUpdateHandler` | заглушка `IUpdateHandler` для тестов, которым нужен только DI |

## Что уже вскрылось на прогонах

- Забой свина **удаляет** его вместе с кормёжками (каскад) и создаёт нового с весом 1.
  Поэтому `/history` показывает только текущую жизнь: без `--no-slaughter` график
  у забивающих стратегий обрывается на 60-м дне.
- Эффект ачивки `NoOverfeed` усиливает luck, а `amount = MAX_FEED_AMOUNT * luck`,
  поэтому средняя прибавка за кормёжку у спокойного свина может быть больше 20 кг.
- Кормить чаще, чем раз в ~8 часов, смысла нет: `Overfeed6` и `Overfeed4` тонут в
  throwup'ах (на 200 днях — 1177 и 22 кг против ~4300 кг у остальных).
